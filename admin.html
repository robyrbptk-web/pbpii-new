Pusat bantuan

Ringkasan tempat data dan akun website disimpan, agar mudah ditemukan lagi.

Di mana database disimpan?

Semua konten tersimpan di satu Google Spreadsheet yang terhubung ke Apps Script website.

  1. Buka spreadsheet yang pernah dipakai, lalu Extensions > Apps Script.
  2. Sheet Articles, Settings, dan Gallery adalah tabel datanya.
  3. ID spreadsheet tersimpan di Script Properties sebagai SPREADSHEET_ID.

Akun admin

Username selalu admin. Password tidak pernah disimpan di website.

  1. Buka spreadsheet dan tunggu menu PB PII muncul.
  2. Pilih Atur akun admin, isi password baru dua kali, lalu simpan.
  3. Bila menu belum ada, jalankan setup() di Apps Script lalu muat ulang spreadsheet.

Jika login gagal

Password hanya tersimpan di Script Properties Google, jadi tidak dapat dilihat dari dashboard.

  • Atur ulang lewat PB PII > Atur akun admin.
  • Pastikan URL deployment Apps Script di api/pii.js masih aktif.
  • Sesi login berlaku 6 jam, lalu masuk kembali.

Masuk sebagai Administrator · sesi berakhir otomatis setelah 6 jam.
